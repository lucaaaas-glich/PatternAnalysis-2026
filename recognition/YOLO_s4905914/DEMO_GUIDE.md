# 数据准备：理解与演示

## 本阶段在做什么

输入是 ISIC 的皮肤镜照片及人工分割 mask，输出是 YOLO 使用的病灶框标注和检查图。
这一步没有训练模型，也没有模型预测；图中的绿色框是从人工 mask 算出的 ground truth。

| 项目 | 表示什么 | 在本项目中的作用 |
| --- | --- | --- |
| RGB image | 病灶照片，包含皮肤、病灶、毛发等 | 模型的输入 |
| Binary mask | 白色像素为人工标注的病灶，黑色为背景 | 提供病灶位置的正确答案 |
| Bounding box | 包住全部病灶像素的最小轴对齐矩形 | 用作目标检测监督标签 |
| YOLO label | 类别编号及归一化的框中心、宽、高 | 供后续训练和评估读取 |

分割（segmentation）回答“哪些像素属于病灶”；检测（detection）回答“病灶在哪里”；
分类（classification）回答“它属于什么类别”。当前类别只有 lesion，类别编号为 0。
编号 0 不代表良性、不代表无病灶；也不是 confidence score。

## mask 如何变成框

横向是 x，纵向是 y，左上角为原点。找到所有非零 mask 像素的最小/最大 x、y。
代码把右边和下边记录为最后一个病灶像素位置 + 1，保证单像素病灶仍有正面积。
一个 mask 中不连通的区域在本阶段仍合成一个框，不会擅自拆成多病灶。
空 mask 会报错，而不会自动当作健康图片。

YOLO 每行的格式是 `class center_x center_y width height`，后四项均为 0 到 1 的比例。

例如照片宽 100、高 80，病灶覆盖 x=10…29，y=20…35：

- 边界为 (10, 20, 30, 36)，框中心为 (20, 28)，宽 20、高 16。
- 除以照片宽、高后，标注为 `0 0.20 0.35 0.20 0.20`。
- 长方框会包含部分背景，丢失精确轮廓。这是把分割标注转换成检测标注的代价。

## 打开结果

从仓库根目录查看 `data/inspection/isic2018_val/previews/`。
每张预览依次显示原图、人工 mask、从 mask 导出的框。
检查框是否与照片中的病灶对应、是否包住全部白色像素、是否出现明显尺寸或配对错误。
视觉检查之外，程序检查配对数量、尺寸、二值 mask 和归一化范围。

运行（PyCharm 解释器应选择已验证的 Python 3.12）：

```powershell
py -3.12 recognition/YOLO_s4905914/dataset.py --images data/raw/ISIC2018_Task1-2_Validation_Input --masks data/raw/ISIC2018_Task1_Validation_GroundTruth --output data/inspection/isic2018_val
```

`summary.json` 给出有效配对数量与框面积范围；`annotations.csv` 记录每张图的坐标；
`labels/` 中每张图对应一个 TXT 标注文件。原始数据和生成结果都在 Git 忽略的 data 目录。

## 学校mask的灰度问题与候选处理（2026-10-12）

学校完整审计已检查2594组，照片与mask配对及尺寸正常，但全部mask不满足当前0/1/255的严格像素规则。学生进一步读取3张：都是L模式、uint8、范围0至255，却分别有230、215、245种灰度值。L/uint8仅说明像素表示方式，不保证内容只有黑白两种。

新增候选诊断，不直接采纳处理规则：

- `pixel >= 1`：所有非零像素当病灶，可能把很暗的灰度边缘也算入。
- `pixel >= 128`：作为中间分界的候选；127归背景，128归前景。不是教师指定值、不是诊断概率，也不是验证过的最佳值。
- `pixel >= 255`：只保留纯白区域，可能缩小或擦除病灶区域。

对照图显示照片、原始灰度mask、候选二值mask和三个阈值下的外接框。先审阅它们，再核对官方原始标注或学校预处理来源；不能把可能的缩放/插值原因当作已证实的原因。对已有灰度mask二值化也不能保证恢复原来每个像素的轮廓。

这里的阈值处理的是**训练答案的像素值**。后续confidence阈值处理的是**模型预测的检测分数**，两者目的不同。

原始数据不改动，正式 `mask_to_bbox` 的严格规则保持不变。`diagnose_masks.py` 只生成候选诊断图和JSON，不导出训练标签，也不产生模型性能结果。

学校3张对照图已取回并由AI辅助浏览：灰度中间像素约占0.55%至1.01%，三个阈值得到的框边界相差最多4像素。随后取官方原始mask作参照：这3张只有0/255，原尺寸1022×767；按学校照片511×384最近邻缩放后，与128候选框的框IoU为0.997653、0.973333、0.990000。这里比较的两边都是**答案的不同处理版本**，不是预测框和答案，不能作为模型性能提交。也未比较全部像素轮廓或完整2594组。

下一步拟用官方二值mask作为正式标签来源，按对应照片尺寸最近邻生成和全量审计，保留学校灰度实验作为处理敏感性记录。最近邻只能保留输入已有的像素值，不会像插值方法那样制造中间灰度；但下采样仍可能损失细小区域。因此还需要全量检查和有代表性的视觉复核。该正式准备步骤尚未执行。

全量程序现已准备并通过测试，学校执行仍待提交。你需要能解释它的流程：**照片和官方mask按编号配对 → 检查原mask确为二值且尺寸约2倍 → 最近邻缩放mask到照片尺寸 → 检查病灶仍非空 → 求外接框并归一化 → 全部通过后导出YOLO标签**。源数据不改动，class 0仅表示lesion。启动脚本自动激活环境并提交CPU任务；这属于工具操作，不是训练原理。任何一组异常都会阻止全量标签导出，因此任务报错不是自动删除异常病例的理由。

`L`的定义、最近邻和插值重采样见 [Pillow官方说明](https://pillow.readthedocs.io/en/stable/handbook/concepts.html)。最近邻从输入选取现有像素值；双线性等方法计算插值值。因此对离散类别mask缩放通常采用最近邻以保留标签值，但目前还不知道学校 `_x2` 实际用了哪种方法。
