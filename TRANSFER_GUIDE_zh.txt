转移与复核

1. 在压缩包目录校验整个包：
   sha256sum -c comp3710_project3_reproducibility.zip.sha256
   macOS 使用 shasum -a 256 -c。

2. 解压到新目录，在根目录使用 Python 标准库核查：
   python recognition/YOLO_s4905914/transfer.py verify --directory .
   压缩包核验拒绝未列入清单的条目；解压目录核验仅检查清单内文件，
   允许之后产生 outputs/。改动已有文件会使原清单核验失败，应记录新版本。

3. 阅读 README、READINESS_STATUS_zh.txt 和评估汇总。只做计划的命令：
   python recognition/YOLO_s4905914/train.py plan \
     --config recognition/YOLO_s4905914/experiment_provisional.json \
     --prepared data/known_lesion_v1
   应为 train=768、val=165、reassessment=165。原 experiment.json 的
   训练开关仍关闭；实际候选配置已锁定，不能把它误当成教师批准。

4. 可从来源重放标签到新目录：
   python recognition/YOLO_s4905914/prepare_dataset.py \
     --sources sources.json --protocol PROTOCOL.json \
     --output outputs/replayed_labels
   三个 CSV 与 1,098 个标签应逐字节一致。summary.json 中机器路径可不同。
   重放分组：
   python recognition/YOLO_s4905914/plan_group_splits.py \
     --metadata data/source_snapshots/collection_63_metadata.csv \
     --historical-splits data/source_snapshots/historical_splits \
     --output outputs/replayed_groups --seed 3710
   生成的 known_lesion/manifest.csv 应与
   data/source_snapshots/known_lesion_manifest.csv 逐字节一致。

5. 本机 macOS 和学校 Linux/A100 已实际通过环境与流程检查。新机器仍应
   使用独立 Python 3.13 环境和固定依赖，执行 pip check 与测试；不要
   静默换版本。requirements-report.txt 对应独立文档导出环境。

6. 优先复核已有结果，完整原始结果另行恢复后可运行 compare_validation.py
   和 analyse_reassessment.py，它们不重新训练或预测。权重与选择锁需
   成对恢复并校验。学校启动脚本记录历史项目路径，新机器不能假定存在。
   如明确需要复现训练，按 RUNBOOK 中直接命令使用实际候选配置，在新
   输出目录和已获分配的 GPU 上执行；保留原始结果和完整曝光历史。
