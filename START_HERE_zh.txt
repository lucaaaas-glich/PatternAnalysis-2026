为什么重做

旧图片级划分存在已知病灶和患者跨集合。标签转换没有发现当前错误，
但评估独立性不足。老师已明确建议用 lesion_id 防止同一病灶跨集合。
重做修正实验设计，不表示原来的图片、标签、代码和全部发现作废。

新版本的具体候选设计

只使用有记录 lesion_id 的 1,098 张：824 良性、274 恶性。
缺失 lesion_id 的 1,496 张不进入此子集的任何阶段，包括训练阶段。
唯一的 Indeterminate 图不属于该子集，因此新版本是两个输出类别：
0 = Benign；1 = Malignant。这是数据子集规则的结果，不是把它改成良性。

集合             总数     良性     恶性
train            768      576      192
val              165      124       41
reassessment     165      124       41

seed = 3710。先按真实 lesion_id / patient_id 的已知相等关系连成组，
再按组分配，尽量接近 70/15/15 和类别比例。共 1,043 个分配组；
它们不是新造的病灶 ID。真实病灶数为 1,083；若多个病灶属于同一已知
患者，分配组可以包含多个病灶。三集合的已知病灶和患者交集均为 0。

仍有 708 张缺少 patient_id。准确表述是：
“在记录 ID 可信的前提下，所选子集按病灶分组，并避免已知患者跨集合。”
不能表述成已证明整个子集患者独立。
课程是否接受缩小至此子集，仍需老师回答 TEACHER_QUESTIONS.txt 的问题 1。

旧 test 已暴露怎样处理

重分配不清除历史。新 val 的 165 张中，120 张曾在旧 train；新
reassessment 的 165 张中，122 张曾在旧 train。所以：
1. 旧拟合 checkpoint 不用作新实验初始化，也不直接用来给新划分评分。
2. n 和 s 都从各自原始 COCO 预训练权重开始。
3. 只用新 val 选择阈值、设置；选择规则在看分数前写清。
4. reassessment 只在方案锁定后评估，明确是补充、回顾性评估，不是新盲测。
5. 新旧实验不能直接用 Recall 的差值证明模型进步，因为样本和分组都变了。
